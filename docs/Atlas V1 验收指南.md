# Keeproot 试用指南

适用版本：2.0.0-preview.1

这次用自带的两份小表格试用。不需要准备自己的材料，也不需要先让 AI 写文章。表格和处理方法都已经准备好。

## 从哪里开始

打开开发者提供的示例入口，在“项目”里选择“示例：合并两份地区数据”。

安装和重开请看[使用说明](<./Atlas V1 使用说明书.md>)。如果界面是英文，点左下角 Settings，把 Interface language 改为简体中文，然后点 Save and close。

左边上半部是项目、活动和导入；中间显示你正在看的项目；最下面的齿轮是设置。

## 先做这五件事

### 1. 看看材料能不能直接读

点“材料与阅读”，打开 `01_资料`，双击 `本期.csv`。

应该在 Keeproot 里看到一张小表格，两条数据的金额是 100 和 80。点“返回资源列表”后，应该仍在刚才的文件夹，刚才的文件仍被选中。

### 2. 看看文字和界面是否舒服

点左边最下面的“设置”。试一个喜欢的主题，调字体、字号和行距，再点“保存并退出”，回到原页面。应用缩放可以在 85%–125% 之间选择；Windows 的显示缩放由系统设置控制。

看看文字是否清楚、按钮是否好找。这里只需要你的感受，不用逐个主题打分。

### 3. 自己保存一份新成果

点“工作概览”，再点“继续工作”。如果打开的是以前的成果，先点“返回工作”。

点“保存完整成果”，选 `02_成果`、CSV，文件名填 `我的第一次试用.csv`。再点“确认保存位置”和“保存并验证”。

处理方法已预先设好，不需要你重新配置。遇到重名提示就换一个名字。

### 4. 检查刚保存的文件

点“阅读已保存成果”。应该有三条数据，金额分别是 **100、80、20**。你可以核对这三个数相加等于 **200**；这个合并示例没有添加“合计”行，阅读页面也不会自动求和。

原来的两份表格和旧成果应该还在。新成果是一份新文件。

### 5. 关掉以后还能不能找到

关闭窗口，再用同一个示例入口打开。进入刚才的项目，在“工作概览”里找到你起的新文件名，打开看看。

保存的显示设置也应该还在。
