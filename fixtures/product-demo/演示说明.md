# 两份资料，一份可继续的成果

这些是虚构数据，不含客户或个人资料。

| 目录 | 用途 |
|---|---|
| 01_资料 | 保留原始输入与本说明 |
| 02_成果 | 保存 Atlas 验证的合并结果 |

## 预置演示方案

1. 明确对齐 `id`、`region`、`amount`。
2. 合并 [本期资料](本期.csv) 和 [补充资料](补充.csv)。
3. 按 `id` 去重，再按 `id` 升序排列。

> 两份 CSV 共四条输入；结果应为三条，金额合计 200。
> 这是预置方案，不代表 Host 认识库或真人认可分类规则。

在 Atlas 中阅读、查看 Work 和来源，然后打开生成后的合并结果。
生成结果不会覆盖输入。演示页面可以准备 Board 的 HTML 交付；预览和候选本身不是保存完成。
